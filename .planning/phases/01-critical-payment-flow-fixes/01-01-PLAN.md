<objective>
Fix two bugs in Backend/payments/views.py that together prevent any Paystack payment from ever completing:

1. PAY-01: Variable shadowing crash — `_handle_charge_success` assigns `transaction = Transaction.objects...get(...)` which overwrites the `from django.db import transaction` module import. The subsequent `with transaction.atomic():` then calls `.atomic()` on a model instance (AttributeError). Fix: rename the local ORM result variable from `transaction` to `txn` throughout the entire function scope.

2. PAY-05: The outer `except Exception` in `paystack_webhook` (line 1100-1102) returns `HTTP 500 INTERNAL_SERVER_ERROR`. Paystack treats non-2xx as a delivery failure and retries. Fix: change to return HTTP 200 with the error logged.

Purpose: Without these fixes, every Paystack charge.success webhook crashes silently — no transaction is ever marked success, no booking is ever confirmed, and no receipt is ever generated.
Output: Modified Backend/payments/views.py with both bugs corrected.
</objective>
