# Frontend Requirements & Tech Stack

## System Requirements
- **Node.js**: >= 20.0.0
- **Package Manager**: pnpm (version 10.20.0 is used in this project)
- **Operating System**: Linux, macOS, or Windows (WSL recommended)

## Core Technologies
- **Framework**: Next.js 16 (React 19)
- **Language**: TypeScript 5.9
- **Styling**: Tailwind CSS 4, Tailwind Animate
- **UI Components**: Radix UI (Primitives), Lucide React (Icons), Sonner (Toasts)
- **State Management**: Zustand, TanStack Query
- **Forms**: React Hook Form, Zod (Schema Validation)
- **Maps**: React Map GL, MapLibre GL
- **Charts**: Recharts, Chart.js
